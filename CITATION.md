# How to cite autoslip-noter

If you use **autoslip-noter** in your work, please cite it as follows.

## BibTeX

```bibtex
@software{Mooers2026AutoslipNoter,
  author  = {Blaine Mooers},
  title   = {autoslip-noter},
  version = {0.1.0},
  year    = {2026},
  url     = {https://github.com/MooersLab/autoslip-noter}
}
```

## Plain text

Blaine Mooers (2026). autoslip-noter (Version 0.1.0)
[Computer software]. https://github.com/MooersLab/autoslip-noter

## Note

Please update the version number and year when citing a specific
release.
